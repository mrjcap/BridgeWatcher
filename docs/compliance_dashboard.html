Initial Audit Summary

The initial compliance audit assessed the BridgeWatcher PowerShell module against key industry security benchmarks. While core controls (supply chain management, non-root container configuration, and encrypted communications) were established, several gaps in policy documentation, API key storage, logging feedback, and platform security were identified.

Critical Initial Finding (F-1)

Google Cloud Vision API key was originally passed as a URL query parameter (?key=...). This exposed the credential to middleware logs, WAF headers, CDN logs, and local proxy history.
